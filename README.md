# Extension Restarter (VS Code Family Extension)

<p align="center">
  <img src="icons/logo.png" alt="Extension Restarter" width="128"/>
</p>

A VS Code extension to quickly restart the extension host or access extension details for manual management.

## ✨ Features

- **Quick Restart (Status Bar)**: One-click **refresh icon** in the status bar (bottom right) to restart all extensions instantly.
- **Restart All (Sidebar)**: Button at the top of the sidebar to refresh the extension host.
- **Favorites & Groups**: Organize your most-used extensions into a "Favorites" section.
- **Add/Remove Favorites**: Use the **+** (Add) and **-** (Remove) hover icons to manage your groups.
- **Quick-Open Details**: Click any extension name to open its management page in the editor.
- **Alphabetical Sorting**: Automatically organized for easy access.

## ⚡ How to use

1. **Install** Extension Restarter from the VS Code Marketplace.
2. **Status Bar**: Click the refresh icon in the bottom right corner for a "Restart All".
3. **Sidebar**: Click the Extension Restarter icon in the Activity Bar.
4. **Favorites**: Click **+** to favorite or **-** to unfavorite an extension.
5. **Details**: Click the extension name to open its details page.

## 🚀 Installation

- Install from [VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=spajs.extension-restarter)
- Command Line: `code --install-extension spajs.extension-restarter`

OR

1. Open VS Code
2. Go to Extensions
3. Search for `extension restarter` and select this extension
4. Click **Install**

## ☑️ Requirements

- VS Code v1.75.0 or higher.
